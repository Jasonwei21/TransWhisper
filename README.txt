语音转文字 · 使用说明
================================================
版本 1.0.0  |   最后更新 2026-11-16
适用环境：Windows 10 / 11（64 位）
配套文档：更新日志.txt（版本变更与更新说明）


一、这是什么
------------------------------------------------
一个完全在本机运行的音视频转文字工具，基于 whisper.cpp
（OpenAI Whisper 的 C++ 实现），带本地图形界面，双击即用。

* 文件不上传、不需要联网、不需要账号，全部处理在本机完成
* 界面是浏览器打开的本地页面，服务只监听 127.0.0.1，
  不会暴露到局域网
* 既可以只转选中的几个文件，也可以批量转写整个文件夹
* 提供图形界面和命令行两种用法


二、快速开始
------------------------------------------------
1. 双击「启动GUI.bat」
2. 浏览器自动打开图形界面（默认 http://127.0.0.1:8765）
   —— 以黑色命令行窗口里显示的地址为准
3. 点「＋ 选择文件」或「＋ 选择文件夹」，在弹出的
   Windows 自带选择框里选好文件
4. 确认输入列表里只出现你要转的文件
5. 点「开始转写」
6. 完成后点「打开结果文件夹」查看 .srt / .txt

关闭那个黑色命令行窗口，服务即退出。

界面是上下结构：
  上半部分：任务进度（左）＋ 运行日志（右）
  下半部分：任务设置，左列是「输入来源」「模型 + 语言」，
            右列是「结果目录 + 输出格式」「提示词」
  「开始转写」「停止」在「任务设置」标题右侧，与进度同屏，
  不用上下翻页。窗口较窄时会自动变成单列。


三、选择输入文件
------------------------------------------------
* 「＋ 选择文件」
  弹出 Windows 原生的文件选择框，按住 Ctrl / Shift 可多选。
  只添加你选中的文件，不会把同目录其他音视频带进来。
  选择框会自动钉在最前面，不会被浏览器窗口挡住。
* 「＋ 选择文件夹」
  弹出系统文件夹选择框。选中后，该目录及其子目录下
  所有支持的音视频都会加入任务 —— 这是批量转写的入口。
* 「或粘贴路径」
  把文件或文件夹的完整路径粘贴进输入框后回车，也能加入。
* 「清空」移除全部待转项；列表每行右侧的 ✕ 可单独移除。
* 点「取消」或按 Esc 关闭选择框，不会添加任何东西。

注意：拖拽上传功能已移除，不要把文件拖到页面上。
      工具直接引用你本机的原始文件，不复制、不上传。

支持的输入格式：
  音频  wav  mp3  flac  m4a  aac  ogg  opus  wma  amr  aiff
  视频  mp4  mkv  mov  avi  flv  wmv  webm  ts  m4v  mpg  mpeg

扫描时自动跳过回收站、系统目录和隐藏目录
（$RECYCLE.BIN、RECYCLER、System Volume Information，
以及 $ 或 . 开头的目录），删掉的文件不会被误转写。


四、结果目录与输出
------------------------------------------------
* 结果只写入「转写结果目录」这一个位置，默认是工具目录下的
  「转写结果」文件夹；点「浏览」可改成任意目录。
* 设置保存在 config.json，重启不丢；便携版拷到别的电脑也跟着走。
  不能把结果目录设在回收站或系统目录，会被拒绝。
* 「打开结果文件夹」直接弹出 Windows 资源管理器，
  查看、复制、打开都用系统原生方式（界面里不再做结果预览）。
* 输出格式二选一或全选：
    SRT 字幕   带时间轴，可导入剪辑软件
    TXT 纯文本 无时间轴，直接阅读
  至少要勾一个，勾选状态会记住。
* 选中整个文件夹转写时，默认按原目录结构生成结果；
  想全部平铺到同一层，勾「结果平铺」。
* 默认跳过已存在的结果（便于断点续转）；要强制重转，
  勾「已有结果也重转」。


五、模型、语言与其他设置
------------------------------------------------
模型（按准确率从高到低）：
  large-v3  模型文件 2.9GB，运行约 4GB 内存，最准但最慢
  medium    1.5GB，约 2GB 内存，中文效果接近 large，日常推荐
  small     466MB，约 0.5GB 内存，最快，适合草稿或长音频粗转

语言：默认「自动检测」，也可手动指定中文、English、日本語、
      한국어、粤语、Русский、Deutsch、Français、Español。
      已知语种时手动选会略快一点。

提示词：写上人名、专业术语（例：张伟、企业微信、腾讯云），
        能明显提高这些词的识别准确率。

高级设置（默认不用动）：
  线程数            0 = 自动（物理核心的 75%，快且不抢系统资源）
  并行文件数        每多一路约多占 3~4GB 内存，建议保持 1
  翻译成英文        输出英文译文
  启用 GPU 加速     Intel 核显会与屏幕显示抢资源、导致鼠标卡顿，
                    工具检测到这类显卡时会自动按 CPU 模式运行
  Flash Attention   GPU 模式下更省显存
  已有结果也重转    见上
  结果平铺          见上

顶栏系统监控：CPU 温度、CPU 占用率、内存占用率、GPU 温度。
CPU / 内存每 2 秒刷新，温度每 15 秒刷新。GPU 温度多数
笔记本不向系统开放，此时显示 --，属正常现象。


六、速度与资源占用
------------------------------------------------
* 采用常驻推理引擎：模型只加载一次，之后逐文件推理。
  实测 10 秒音频约 1.2 秒转完；批量任务不再每个文件重载 3GB 模型
  （相比早期版本约快 12 倍）。
* 任务结束 5 分钟无新任务，引擎自动退出并释放模型内存；
  点「停止」立即释放。
* 推理 / 转码进程以低于正常优先级运行：空闲时全速跑，
  动鼠标时自动让路。
* 常驻引擎万一出问题，会自动回退到单文件 whisper-cli 模式，
  不影响出结果。
* 本工具空闲时 CPU 占用为 0（顶栏监控可自行核对）。


七、便携版（拷到其他电脑用）
------------------------------------------------
位置：便携版\
把整个「便携版」文件夹拷到 U 盘或别的 Windows 电脑，
双击里面的「启动GUI.bat」即可，无需安装 Python 或任何依赖。

自带内容：Python 运行环境、ffmpeg、whisper 引擎、
          CPU-only 引擎副本、三个模型（合计约 4.9GB）。

打包 / 升级命令（在工具主目录执行）：
  python 制作便携版.py                           完整打包
  python 制作便携版.py --models medium,small      只带部分模型
  python 制作便携版.py --out D:\语音转文字        指定输出位置
  python 制作便携版.py --no-python               不带 Python
  python 制作便携版.py --out 便携版 --only-code   只更新代码和文档
                                                 （模型/引擎不动，升级用）

想省空间：删掉 便携版\tools\whisper\ 下用不到的 .bin 模型文件。


八、命令行用法
------------------------------------------------
python transcribe.py <文件或文件夹...> [参数]

  -o, --output DIR      输出目录（默认「转写结果」）
  -m, --model NAME      模型文件名（默认 ggml-large-v3.bin）
  -l, --language LANG   语言代码：auto/zh/en/ja/...（默认 auto）
  -t, --threads N       每进程线程数，0 = 自动
  -w, --workers N       并行文件数（默认 1）
      --formats LIST    输出格式，逗号分隔：
                        srt,vtt,txt,lrc,csv,json,jsonfull（默认 srt,txt）
      --prompt TEXT     提示词
      --translate       翻译成英文
      --no-gpu          强制 CPU 推理
      --flash-attn      开启 flash attention
      --overwrite       已有结果也重转
      --flat            结果平铺，不保留子目录结构

注意：图形界面只提供 SRT / TXT 两种格式；
      七种格式仅在命令行版可用。

示例：
  python transcribe.py "D:\录音" -o "D:\结果" -m ggml-medium.bin
  python transcribe.py "D:\会议.mp4" -l zh --prompt "张伟,腾讯云"
  python transcribe.py "D:\录音" --formats srt,txt,lrc --overwrite


九、常见问题
------------------------------------------------
Q: 双击 启动GUI.bat 提示找不到 Python？
A: 便携版自带 python 文件夹，确认它和 bat 在同一层。
   本机使用可安装 Python 3 并勾选 "Add python.exe to PATH"；
   装了仍找不到时，到「设置 > 应用 > 高级应用设置 >
   应用执行别名」关掉 python.exe / python3.exe 的商店占位符。

Q: 杀毒软件报毒 / 拦截？
A: 属于误报。程序已针对启发式规则做过专门治理：
   - 全程不调用 PowerShell（系统信息用 Windows API 直读，
     温度用微软签名的 typeperf）
   - 运行时直接使用打包时预置的引擎，正常情况零复制、零释放 exe
     （仅当预置目录意外缺失时才补齐一次）
   - 已移除全部上传接口，服务端不再接收任何文件写入
   仍可能报的原因：whisper 引擎与 ffmpeg 是未数字签名的
   开源二进制，容易被保守的启发式规则波及。处理办法：
   1) 把整个工具文件夹加入杀毒软件的排除 / 信任列表；
   2) 用「校验值-SHA256.txt」核对文件哈希，可对照
      whisper.cpp / ffmpeg 官方发布逐一比对。

Q: 文件选择框没弹到最前面？选完文件列表里没出现？
A: v14 已修复这两处（置顶看护、返回缓冲区解析、中文路径
   UTF-8 回传）。若看到的还是旧界面，按 Ctrl+F5 强制刷新。

Q: 浏览器没自动打开 / 页面打不开？
A: 看黑色命令行窗口里显示的真实地址。端口 8765 被占用时
   会自动换随机端口，以窗口显示为准。也可以在浏览器里
   手动输入该地址。

Q: 转写时鼠标卡顿？
A: 推理进程已自动降优先级；Intel 核显请保持
   「启用 GPU 加速」关闭（工具默认就会关）。

Q: 内存占用大？
A: 是模型本身：large-v3 约 4GB、medium 约 2GB、small 约 0.5GB。
   日常用 medium 即可，并行文件数保持 1。任务结束 5 分钟后
   模型内存会自动释放。

Q: 会不会把回收站里删掉的文件也转了？
A: 不会，扫描时自动跳过回收站、系统目录和隐藏目录。

Q: 结果在哪里？为什么界面不显示结果列表？
A: 结果预览面板已移除（此前反复出问题），改为
   「打开结果文件夹」按钮，在资源管理器里查看。
   文件就在你设置的结果目录中。


十、已知限制
------------------------------------------------
* 仅支持 Windows 10 / 11 64 位；GPU 温度依赖主板与驱动是否开放，
  多数笔记本读不到。
* 引擎二进制没有数字签名，极少数杀软仍可能误报，加白名单即可。
* 同一时间只能跑一个任务，运行中不能提交新任务。
* 数小时的超长单文件推理耗时较长，属模型本身特性。


十一、文件清单
------------------------------------------------
工具主目录：
  启动GUI.bat         启动入口（自动查找可用 Python）
  server.py           本地服务端 / 图形界面接口
  transcribe.py       转写核心 + 命令行入口
  filepick.py         Windows 原生文件选择框（Win32 API）
  web\                界面文件（index.html / app.js / style.css）
  转写结果\           默认结果目录
  config.json         用户设置（结果目录）
  制作便携版.py       便携版打包工具
  便携版\             打包好的独立版本
  README.txt          本文件
  更新日志.txt        更新说明 + 完整版本历史

便携版额外包含：
  python\             自带 Python 运行环境
  tools\ffmpeg.exe    转码工具
  tools\whisper\      whisper-cli / whisper-server / 模型
  tools\whisper-cpu\  不含 Vulkan 的 CPU-only 引擎副本
  校验值-SHA256.txt   引擎文件哈希清单（误报时用于核对）
  使用说明.txt        便携版简版说明

说明：主目录下的 _uploads\、__pycache__\、_gui_out\ 等是历史运行
残留或缓存目录，功能已不使用，可以安全删除。
