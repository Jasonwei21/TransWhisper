内测版更新说明（v14，文件选择返工，内测版收尾）
------------------------------------------------
这一次是「文件怎么进来」的整体返工，解决此前选择文件体验差、
以及选完之后没有反应的问题。

1. 输入改为 Windows 自带的文件选择框
   「选择文件 / 选择文件夹 / 结果目录浏览」全部调用系统原生
   资源管理器对话框，返回真实磁盘路径。选什么就是什么，
   不再经过网页里的自定义弹窗，也不需要任何"上传"。

2. 修好了「点一个文件，把同目录所有音视频都带进来」
   问题的根源在旧的自定义浏览弹窗，v14 已把整套弹窗移除，
   错误路径不复存在。单文件选择只加入你选中的那几个。

3. 修好了「选完文件，界面里不显示」
   这是一个实打实的解析错误：对话框返回的多选缓冲区读取方式
   写错，导致路径在传回界面的最后一步抛异常。现已修复，
   并补上 UTF-8 输出（中文路径不会乱码）、取消与超时的兜底处理。
   实测中文路径可正确回传。

4. 对话框自动置顶
   加了置顶看护线程，弹出后会被设为最顶层并激活，
   不会再躲在浏览器窗口后面。

5. 关闭批量拖拽上传
   拖拽区、上传暂存区（_uploads）和相关接口整体移除。
   工具直接引用本机原始文件，不复制、不上传；
   批量转写请用「选择文件夹」。

6. 顺带完成
   接口参数校验、对话框异常按取消处理、界面添加成功提示。

升级方式：浏览器按 Ctrl+F5 强制刷新即可，服务无需重装。
         便携版执行 python 制作便携版.py --out 便携版 --only-code。

[v13] 杀毒误报治理（重要）
  - 系统信息采集改用 Windows API 直读（ctypes），不再调用 PowerShell

    这一被杀软重点盯防的行为特征
  - 上传接口限定只接收音视频文件（该接口连同拖拽功能已于 v14 移除）

  - 显卡名称去重，温度解析按可解析数据行取值（typeperf 尾部提示文字
    不再干扰读数）
  - 新增 README.txt 使用说明与本更新日志
